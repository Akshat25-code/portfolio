## 🌟 Highlights

- **🪐 3D Celestial Solar Skills System**:
  - Interactive HTML5 Canvas cosmic engine with 8 concentric planetary orbits.
  - Symmetrically distributed, 100% unique skill logo badges with custom vector emblems.
  - Directionally lit planetary bodies, Earth's Moon with circular orbital track, and dynamic collision asteroids with spark particle flares.
  - Dedicated on-canvas zoom controls (`+` / `−` / `↻`) with zero scroll hijacking.
- **🧭 Bento "About Me" Grid**:
  - Continuous typewriter cycling across 6 engineering roles.
  - Interactive 3D flip cards for education and certifications.
  - Real-time radar clock with IST coordinate telemetry.
- **🚀 Featured Engineering Projects**:
  - **Adaptive RAG**: Agentic query-routing pipeline with vector search and self-correcting response validation.
  - **AI Code Optimizer**: Multi-model benchmarking platform with isolated execution sandboxes and SARIF security scanners.
  - **AirBnb Backend**: Scalable Spring Boot hotel engine with pessimistic locking and Stripe webhook workflows.
- **💬 Interactive AI Chatbot**:
  - Draggable, floating intelligent assistant capable of answering questions about Akshat's background, skills, and projects.
